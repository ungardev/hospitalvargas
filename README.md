# Hospital Vargas de Caracas

Sitio web oficial del Hospital Vargas de Caracas, Caracas, Venezuela. Segundo centro hospitalario más importante del país.

## 🚀 Características

- ⚡ **Alto Rendimiento** - Build estático con Astro, <2s tiempo de carga
- 🎨 **Diseño Profesional** - Tema azul institucional
- 📱 **Responsive** - Adaptado para todos los dispositivos
- 🔍 **SEO Optimizado** - Meta tags, Open Graph, sitemap
- 🏥 **32 Especialidades Médicas** - Servicios de salud especializados
- 📊 **132 Programas de Postgrado** - Formación médica continua
- 🩸 **Banco de Sangre** - Centro de referencia nacional

## 📁 Estructura

```
/
├── public/
│   └── images/          # Imágenes del hospital
├── src/
│   ├── components/      # Componentes UI
│   ├── data/           # Configuración y datos
│   ├── layouts/        # Layouts de página
│   ├── pages/          # Rutas de página
│   ├── scripts/        # Scripts (Lenis smooth scroll)
│   └── styles/         # Estilos globales
└── package.json
```

## 🛠️ Comandos

| Comando           | Acción                           |
| ----------------- | -------------------------------- |
| `npm install`     | Instalar dependencias            |
| `npm run dev`     | Servidor local en localhost:4321 |
| `npm run build`   | Build de producción en ./dist/   |
| `npm run preview` | Previsualizar build              |

## 📋 Páginas

- `/` - Inicio
- `/historia` - Historia del hospital
- `/servicios` - 35+ especialidades médicas
- `/banco-de-sangre` - Banco Municipal de Sangre
- `/pregrado` - Programas de pregrado (UCV)
- `/postgrado` - 132 programas de especialización
- `/estadisticas` - Indicadores de gestión
- `/noticias` - Novedades y eventos
- `/contacto` - Información de contacto

## 🏥 Sobre el Hospital

El Hospital Vargas de Caracas fue fundado el 5 de julio de 1891 en Caracas. Es un hospital tipo 4 con área de influencia de más de 400 mil habitantes y centro de referencia nacional.

**Dirección:** Monte Carmelo a San Pirito, Esq. del Hospital, Parroquia San José, Caracas
